# Authorship and Git Rules

This repository is owned and authored by Lea Azar.

Never add Claude, Anthropic, an AI assistant, or any model as:
- a Git co-author;
- a contributor;
- a collaborator;
- an author in documentation;
- a commit trailer;
- a pull-request attribution;
- a README acknowledgment.

Never add:
- Co-Authored-By: Claude
- Generated with Claude Code
- Written by Claude
- Any equivalent attribution

Use only the Git user.name and user.email already configured by the repository owner.

Before every commit, inspect the full commit message and remove all AI attribution.
Before every push, confirm that no raw data, credentials, tokens, institutional files, or licensed datasets are staged.
